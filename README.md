# Grand Large Quiz

Pub quiz statique sur le thème mer, océan et plage.

## Ouvrir en local

Double-cliquer sur `lancer-quiz.bat`, ou ouvrir `index.html` dans un navigateur.

## Publier sur GitHub Pages

Le site est statique : `index.html`, `styles.css` et `app.js` suffisent pour GitHub Pages.

Dans les paramètres du dépôt GitHub :

1. Aller dans **Settings**.
2. Aller dans **Pages**.
3. Choisir **Deploy from a branch**.
4. Sélectionner la branche `main` ou `master`, dossier `/root`.
5. Enregistrer.

Le blind test utilise des embeds YouTube. Si certains extraits sont bloqués par YouTube, il faudra passer à des fichiers audio locaux.
